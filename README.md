# Senior TL / EM Interview Prep

Twelve self-contained question banks for Senior Tech Lead and Engineering Manager interviews, with a focus on .NET, Node.js, AWS and AI/GenAI. Open `index.html` (or the GitHub Pages site) to start.

| Bank | File | Questions |
|---|---|---|
| Leadership & Behavioral | `leadership.html` | 90 |
| System Design Drills | `system-design.html` | 45 |
| Architecture & Distributed Systems | `architecture.html` | 90 |
| AI & GenAI | `ai-genai.html` | 90 |
| .NET Backend | `dotnet.html` | 90 |
| Cloud & DevOps | `cloud.html` | 90 |
| Data Layer | `data.html` | 90 |
| Security, Testing & Observability | `security-testing-observability.html` | 60 |
| Node & NestJS | `node.html` | 50 |
| Frontend | `frontend.html` | 40 |
| LLD & Machine Coding (C#) | `lld.html` | 30 |
| DSA Refresher (C#) | `dsa.html` | 47 |

Each page has search, filters by skill, level and type, collapsible answers and follow-ups, and a "Mark as reviewed" progress counter. Progress is stored in your browser's local storage only.

## Notes

- Items marked **[VERIFY]** depend on vendor limits, pricing, versions or regulations that change; check them against current documentation.
- The C# code in the LLD and DSA banks was reviewed but not compiled; build and run it as part of practice.
- Leadership answers are STAR templates; replace each story with a true one of your own.
