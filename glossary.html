A

ACID
Atomicity, Consistency, Isolation, Durability: the guarantees of a database transaction.Practise: N025 · Q004
ADR
Architecture Decision Record: a short document capturing a decision, its context, options and consequences.See: Architecture bank · Leadership bank
ALB / NLB
AWS Application Load Balancer (HTTP-aware, layer 7) and Network Load Balancer (TCP/UDP, layer 4).Practise: C002
API gateway
Edge service handling routing, authentication, rate limiting and request validation in front of backend services.Practise: K005 · A013
async/await
Language feature for writing non-blocking code sequentially; the thread is released while awaiting I/O.Practise: N002 · N019
Autoscaling
Adding or removing capacity automatically based on metrics such as CPU, requests or queue depth.Practise: K076
Availability zone
An isolated data-centre group within a cloud region; spreading across AZs protects against a single facility failure.Practise: K010 · K053

B

Backpressure
A signal from a slow consumer telling producers to slow down, preventing unbounded queues.Practise: J012 · N054
Big-O
Notation describing how time or memory grows with input size, ignoring constants.Practise: D001
Blue-green deployment
Running two production environments and switching traffic from the old (blue) to the new (green) for instant rollback.Practise: K017
Bounded context
A DDD boundary inside which a model and its terms have one consistent meaning.Practise: N086 · A069
Bulkhead
Isolating resources (pools, queues) per dependency so one failure can't exhaust everything.Practise: A014

C

Cache-aside
The application reads from the cache, falls back to the database on a miss, then fills the cache.Practise: Q017 · Q018
Canary release
Sending a small share of traffic to a new version and widening only if metrics stay healthy.Practise: K017 · K074
CAP theorem
During a network partition, a distributed system must choose consistency or availability.Practise: A015
CDN
Content Delivery Network: caches content at edge locations close to users.Practise: K009 · F034
Change data capture (CDC)
Streaming row-level changes from a database's log to other systems.Practise: Q059 · Q039
Chunking
Splitting documents into pieces for embedding and retrieval in RAG.Practise: G009 · G026
Circuit breaker
A wrapper that stops calling a failing dependency for a cool-down period, failing fast instead.Practise: A014 · L028
Clustered index
An index that defines the physical order of table rows; one per table in SQL Server.Practise: Q001 · Q055
Cold start
Extra latency when a serverless platform creates a new execution environment.Practise: K002 · K003
Connection pooling
Reusing open database connections instead of opening one per request.Practise: N015 · N066
Consistent hashing
A hashing scheme where adding or removing a node remaps only about 1/N of keys.See: Architecture bank · System Design Drills
CORS
Cross-Origin Resource Sharing: browser rules, controlled by server headers, for calls between origins.Practise: T047 · D020
CQRS
Command Query Responsibility Segregation: separate models for writes and reads.Practise: A030
CSRF
Cross-Site Request Forgery: tricking a logged-in browser into sending an unwanted request.Practise: T015

D

Dead-letter queue (DLQ)
A queue that holds messages which failed processing repeatedly, for inspection and replay.Practise: A010 · A037
Dependency injection
Supplying an object's dependencies from outside rather than creating them inside.Practise: N007 · J003
DORA metrics
Deployment frequency, lead time for changes, change failure rate and time to restore service.Practise: B083
DynamoDB partition key
The attribute DynamoDB hashes to place items; it decides scalability and hot partitions.Practise: Q011 · Q012

E

Embedding
A vector representing the meaning of text (or images) so similar items are close together.Practise: G004
Event loop
Node.js's single-threaded loop that runs callbacks when I/O completes.Practise: J001 · J011
Event sourcing
Storing every change as an immutable event and deriving current state from them.Practise: A029
Eventual consistency
Replicas may briefly disagree but converge when writes stop.Practise: A016 · Q041

F

Feature flag
A runtime switch that turns functionality on or off without a deployment.Practise: K017
Fine-tuning
Further training a model on your examples to change its behaviour or format.Practise: G008

G

GC generations
.NET's garbage collector groups objects by age (Gen 0, 1, 2, plus the large object heap) to collect short-lived objects cheaply.Practise: N018 · N033
Guardrails
Policies and filters around an LLM that block unsafe input or output.Practise: G023 · G056

H

Hallucination
A fluent but unsupported or false answer from a language model.Practise: G030 · G043
Health check / probe
An endpoint or check that tells orchestrators whether an instance is alive and ready for traffic.Practise: N034
HNSW
Hierarchical Navigable Small World: a graph-based approximate nearest-neighbour index used by vector databases.Practise: G012
Hot partition
A shard or partition receiving a disproportionate share of traffic.Practise: Q025 · Q038
HttpClient / IHttpClientFactory
.NET's HTTP client and the factory that manages handler lifetimes to avoid socket exhaustion and stale DNS.Practise: N047

I

IAM role
An AWS identity with temporary credentials that services, users or pipelines assume.Practise: K008 · K034
Idempotency
An operation that has the same effect whether performed once or many times; often enforced with idempotency keys.Practise: A017 · A052 · K027
Index (database)
A data structure (usually a B-tree) that speeds lookups at the cost of storage and slower writes.Practise: Q001 · Q002
Infrastructure as Code
Defining infrastructure in version-controlled files (Terraform, CloudFormation, Bicep).Practise: K013 · K014
Isolation levels
Read uncommitted, read committed, repeatable read, snapshot and serializable: how much concurrent transactions can see of each other.Practise: Q004 · Q023

J

JWT
JSON Web Token: a signed set of claims used as a bearer token.Practise: T006 · T004

K

Kubernetes
A container orchestrator that schedules pods, restarts failures and manages rollouts.Practise: K018 · K050

L

Leader election
Choosing one node among many to perform a task or accept writes.Practise: A045
Least privilege
Granting only the permissions a person or workload needs.Practise: K060 · T018
LINQ / IQueryable
C# query syntax; IQueryable builds expression trees translated to SQL, IEnumerable runs in memory.Practise: N003 · N065
Liskov substitution
Subtypes must be usable wherever their base type is expected without breaking behaviour.Practise: L001 · L002
Load shedding
Deliberately rejecting some requests under overload to keep the system serving the rest.Practise: T046

M

MCP
Model Context Protocol: an open standard for connecting LLM applications to tools and data sources.Practise: G021
Microservices
An architecture of independently deployable services, each owning its data.Practise: A011 · A012
Middleware
Components in a request pipeline that can inspect, change or short-circuit requests and responses.Practise: N008 · N031 · J004
Migration (schema)
A versioned, repeatable change to a database schema.Practise: Q016 · Q044 · N069
Modular monolith
One deployable application split into well-bounded modules with enforced boundaries.Practise: A012 · A038
MVCC
Multi-Version Concurrency Control: readers see a snapshot so they don't block writers (PostgreSQL, SQL Server snapshot isolation).Practise: Q007 · Q004

N

N+1 query
Loading a list then running one extra query per item, instead of one joined or batched query.Practise: N013
NAT gateway
Lets resources in private subnets reach the internet outbound only.Practise: K007 · K082
Normalisation
Structuring relational tables to remove redundancy (1NF, 2NF, 3NF); denormalisation trades that for read speed.See: Data Layer bank

O

OAuth 2.0 / OIDC
OAuth 2.0 delegates authorisation with access tokens; OpenID Connect adds authentication (ID tokens) on top.Practise: T004 · T028
Observability
Understanding a system's internal state from its outputs: logs, metrics and traces.Practise: T011 · T024
Optimistic concurrency
Detecting conflicting updates with a version or row-version check instead of locking.Practise: L014 · L025 · N074
Outbox pattern
Writing an event to an outbox table in the same transaction as the business change, then publishing it reliably.Practise: A021 · A051
OWASP Top 10
The Open Web Application Security Project's list of the most critical web application security risks.Practise: T001

P

p95 / p99 latency
The latency under which 95% / 99% of requests complete; tail latency matters more than the average.Practise: T051 · C001
Pagination (cursor vs offset)
Returning large results in pages; cursor/keyset pagination stays fast and stable where offset slows down.Practise: A018 · Q066
Partitioning / sharding
Splitting data across nodes or tables by a key to scale beyond one machine.Practise: Q028 · Q011
Prompt injection
Input that tries to override an LLM's instructions, directly or via retrieved content.Practise: G018

R

RAG
Retrieval-augmented generation: retrieving relevant documents and adding them to the prompt so answers are grounded.Practise: G008 · G010
Rate limiting
Restricting how many requests a client can make in a time window (token bucket, sliding window).Practise: A049 · L007
Read replica
A copy of a database that serves reads, updated asynchronously from the primary.Practise: K010 · Q063
Reconciliation (React)
React comparing the new element tree with the previous one to apply minimal DOM updates.Practise: F001
Redis
An in-memory data store used for caching, sessions, rate limits, queues and pub/sub.Practise: Q018 · Q048
Reranking
Re-scoring retrieved candidates with a stronger model (often a cross-encoder) before passing them to the LLM.Practise: G027
Retry with backoff and jitter
Retrying transient failures after increasing, randomised delays to avoid synchronised retry storms.Practise: A014 · T041
RPO / RTO
Recovery Point Objective (data you can lose) and Recovery Time Objective (downtime you can tolerate).Practise: S043 · A061

S

Saga
A sequence of local transactions with compensating actions, replacing a distributed transaction.Practise: A022 · A053
Security group
An AWS stateful virtual firewall attached to network interfaces.Practise: K007
Server-side rendering (SSR)
Rendering HTML on the server for faster first paint and SEO, then hydrating in the browser.Practise: F004 · F005
Service lifetimes
ASP.NET Core DI lifetimes: singleton (one per app), scoped (one per request), transient (new each time).Practise: N007 · N027
SLI / SLO / SLA
Indicator (what you measure), objective (internal target) and agreement (contractual promise); error budget = 1 − SLO.Practise: T025
SOLID
Single responsibility, Open/closed, Liskov substitution, Interface segregation, Dependency inversion.Practise: L001
Span<T>
A stack-only view over contiguous memory in .NET that avoids allocations when slicing.Practise: N052
SQL injection
Inserting SQL through unsanitised input; prevented with parameterised queries.Practise: T002
Strangler fig
Incrementally replacing a legacy system by routing features to new components one at a time.Practise: T050 · B072
Structured concurrency / Task.WhenAll
Running independent async operations concurrently and awaiting them together.Practise: N021

T

Technical debt
The future cost of shortcuts in code or design; managed deliberately, not eliminated.Practise: B016 · B044
Temperature
An LLM sampling setting; lower is more deterministic, higher more varied.Practise: G002 · G020
Test pyramid
Many fast unit tests, fewer integration tests, few end-to-end tests.Practise: N088 · N016
Thread pool starvation
All thread-pool threads blocked (often by sync-over-async), so queued work waits and latency spikes.Practise: N079
Token (LLM)
The unit of text a model reads and writes; roughly four characters of English.Practise: G001 · G002
Token bucket
A rate-limiting algorithm where tokens refill at a fixed rate and each request spends one.Practise: A049 · L007
Tool use / function calling
The model returns a structured request to call a function you defined; your code validates and executes it.Practise: G015 · G021
Two-phase commit
A blocking protocol to commit a transaction across several resources; avoided between microservices.Practise: N070
TypeScript generics
Type parameters that let functions and types work over many types while keeping type safety.Practise: J020

U

useEffect
React hook for synchronising a component with external systems after render.Practise: F002

V

Vector database
A store with approximate nearest-neighbour indexes for similarity search over embeddings.Practise: G012 · G013
Virtual DOM
An in-memory representation of the UI that React diffs to compute DOM changes.Practise: F001
VPC
Virtual Private Cloud: your isolated network in a cloud region, split into subnets.Practise: K007 · K032

W

WebSocket
A persistent two-way connection over a single TCP connection, used for real-time features.Practise: J009 · J010
Worker threads
Node.js threads for CPU-heavy work so the event loop stays responsive.Practise: J011

X

XSS
Cross-Site Scripting: injecting script into pages other users view; prevented by output encoding and CSP.Practise: T003

Z

Zero-downtime deployment
Releasing without interrupting users: rolling/blue-green deploys plus backward-compatible schema changes.Practise: K077 · Q015
